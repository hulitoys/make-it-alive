# Make It Alive

Make It Alive 把日常照片里的一个物体原地变成原创动漫精灵，同时将完整场景统一动漫化，并直接输出一张带手绘撕页过渡的无文字前后对照图。

## 默认效果

- 自动选择照片中最适合精灵化的一个物体，也支持用户点名。
- 保留原物体的轮廓、颜色或材质、标志性结构细节。
- 将整个场景完整动漫化，在原物位置放入一只原创精灵；墙面、台面、包装、植物、水滴、阴影和背景细节都必须统一重绘，不允许只动漫化精灵、保留摄影背景。
- 使用明亮的二维收集养成类动画语言：彩色线稿、赛璐璐式角色明暗、柔和动漫背景，不复制任何已有角色或品牌元素。
- 最终成品不添加名字、性格、爱好、简介、标题、编号或任何其他文字。

一张输入只输出一张成品；多张输入按原顺序逐张输出。不会先给候选图，也不会让用户选择版本。

## 自适应排版

- 横图：上方为完整原图，下方为动漫精灵场景。
- 竖图：左侧为完整原图，右侧为动漫精灵场景。
- 方图：按竖图规则左右排布。
- 两张图尺寸一致，中间使用无文字的手绘撕页过渡：暖纸底、不规则纤维边、轻微阴影和取自动漫图的彩铅笔触；过渡使用新增区域，不遮挡两张图。
- 原照片文件不会被覆盖或改写。若生成图比例略有偏差，脚本会用柔化延展背景填充，同时保留完整清晰的生成图。

## 安装

在支持自定义 Skill 的环境中从以下路径安装：

```text
https://github.com/hulitoys/make-it-alive/tree/main/skills/make-it-alive
```

如果已经安装旧版本，请重新安装或刷新，并新开一个任务；已经复制到本地或当前会话缓存中的旧 Skill 不会跟随 GitHub 自动更新。

## 使用

上传一张或多张照片，然后输入：

```text
使用 $make-it-alive 处理我上传的照片。
```

也可以指定物体：

```text
使用 $make-it-alive，把照片里的台灯变成精灵。
```

运行端需要具备参考图生成能力，并能执行 Python/Pillow 合成脚本。GitHub 仓库本身不包含图片模型。

## 合成脚本

```text
python skills/make-it-alive/scripts/compose_make_it_alive.py \
  --photo <原照片> \
  --scene <无文字动漫精灵场景> \
  --output <最终 PNG> \
  [--transition-width 48]
```

脚本不使用字体，也不会添加任何文字。默认将每个面板的长边缩放为 1600 像素，使用 48 像素手绘撕页过渡，并保护已有输出文件。旧参数 `--gap` 可继续作为 `--transition-width` 的别名使用。
